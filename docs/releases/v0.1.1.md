# PokeV-Recomp v0.1.1

## Highlights

- **Update Checker & Release Notes Modal (Phase A):** Automatically checks GitHub Releases on startup (respecting `LARECOMP_NO_UPDATE_CHECK=1`, offline/rate-limit states, and external launcher suppression) and displays release notes directly inside the Welcome Screen.
- **Linux AppImage Auto-Updater (Phase B):** One-click in-app update for Linux AppImage builds (`Download & Update` -> SHA-256 verification against `SHA256SUMS` -> atomic backup & swap via detached `/bin/sh` helper -> automatic relaunch).
  - Preserves saves, settings, mods, and compiled game data (`GAMELIB_ID` is unchanged from `v0.1.0`, so no recompilation is required).
  - Includes boot-time recovery from `.bak` and stale `.part`/`.staged`/`.lock` cleanup.
- **UX Polish:**
  - Friendly Markdown rendering for release notes (headings, bold text, inline code, bullet lists, blockquotes, code blocks, and clickable HTTPS links).
  - Wider, responsive release notes modal (`880x580` max) with dynamic layout so action buttons never overlap.
  - Amber-gold warning triangle (`!`) indicator next to available updates.
  - Accurate channel label (`Latest stable` vs `Latest pre-release` when `LARECOMP_UPDATE_PRERELEASE=1` is enabled).

## Assets & Verification

- `PokeV-Recomp-linux-x86_64.AppImage` — Linux x86_64 AppImage
- `PokeV-Recomp-windows-x64.zip` — Windows x64 portable archive
- `SHA256SUMS` — SHA-256 checksums for all release artifacts

Verify integrity on Linux:
```sh
sha256sum -c SHA256SUMS --ignore-missing
```
