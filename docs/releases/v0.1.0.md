# PokeV-Recomp v0.1.0

`v0.1.0` brings opt-in **RecompLauncher** integration, **water reflections** with F1 menu options, **60 fps ride jump** physics fix, long-session performance improvements, and several GPU/rendering fixes on top of `v0.0.30`.

## Highlights
- **RecompLauncher Integration (#50):** Added `recomplauncher.json` to both the Linux AppImage (`AppRun`) and Windows ZIP (`PokeV-Recomp.exe`), with opt-in `--prepare`, `--play`, `LARECOMP_DATA_ROOT`, and `{data}/save/save_0` save/config support, plus Windows symlink/junction resolution in `runtime/path_overlap.h`.
- **Water Reflections & F1 Water Options (#44):** Added screen-space planar reflections (SSPR) and planar scene reflections for water, exposed water options in the F1 menu, and restricted reflections to level water surfaces (leaving window panes unaffected).

## Bug Fixes
- **Miraidon / Koraidon 60 fps Jump (#48):** Synced Lua script frame time to the actual frame delta (`tools/sv_patches.py`, `runtime/hle/framepace.c`; `LARECOMP_SV_LUA_DT=0` disables), fixing half-height jumps at 60 fps.
- **Map Place Names Losing Letters (#46):** Added a 16 MB storage-copy ring past the game's physical memory pool and copied recently CPU-written storage reads on translation.
- **Water Visual & Flicker Fixes (#44):** Fixed waterfall and far-water flickering, seams between water meshes, and tree-reflection streaks in screen-space search.
- **Compute UBO Staging (#43 / #27):** Added 64-bit `gfind` staging for compute-shader UBO reads from secondary guest memory pools.

## Performance Improvements
- **Long-Session Stability & DLAA (#45):** Expanded the transform feedback mirror from 256 MB to 512 MB (preventing system-memory fallback after long play), packed DLAA object-motion mirror copies to only character-read slices, and kept TAA-resolve draws on the render thread in shadow workers.
- **Water & Post-Pass Overhead (#44):** Removed G-buffer draw locking when no water needs mirroring and increased the post-pass Vulkan pipeline cache from 24 to 32 pipeline kinds.

## Compatibility & Requirements
- **Supported Game:** Pokémon Violet **4.0.0** (base + 4.0.0 update + `prod.keys`).
- **RecompLauncher Validation Note:** End-to-end RecompLauncher integration (`AppImage`, `AppRun`, `--prepare`, `--play`, save import/saving, settings persistence, and clean install) was manually validated on **Bazzite Linux**, and automated ZIP/CLI smoke tests passed on **Windows CI (`windows-2022`)**. Full manual gameplay validation on physical Windows has not yet been performed.

## Upgrading from Previous Versions
- **One-time game-code recompilation required:** Because `tools/sv_patches.py` changed for the 60 fps Lua frame-time fix (#48), upgrading from `v0.0.30` will recompile the game code once (typically 10–30 minutes).
- Your existing saves and settings remain compatible.
